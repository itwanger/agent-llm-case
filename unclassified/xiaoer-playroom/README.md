# 小二的游乐时光 · Little Days

一个可以本地运行的 3D 玩具房。Vite + TypeScript + Three.js，采用柔和圆角模型、暖木色、布料纹理和奶油绿配色。

## 本地运行

推荐 Node.js 22；当前项目亦已在 Node.js 20.16 环境构建通过。

```bash
cd unclassified/xiaoer-playroom
npm install
npm run dev
```

打开 **http://localhost:5188/**。使用独立端口以避开本机已有的 5173 服务。Vite 支持源码刷新与 CSS 热更新。

```bash
npm run test     # 导航与动作边界检查
npm run build    # TypeScript 检查和生产构建，输出到 dist/
npm run preview # 本地预览构建结果
```

## 已实现

- 约 60 平方米的拼接软垫，中心留白，包含拱窗、窗帘、暖木地板、护墙板、收纳书架、绘本、阅读角、植物、玩具篮和彩旗。
- 小二：黑发、圆脸、腮红、太阳刺绣背带裤；分层头部、肩肘、髋膝关节，眨眼、呼吸、转头与步行动作。
- 七种互动玩具：彩虹积木、绘本、木琴、小熊、皮球、攀爬城堡与滑梯、摇摇木马。
- 自主随机选择、避免连续重复、A\* 避障行走、平滑转身和动作过渡。攀爬或骑乘途中选择新玩具，会在安全落地后继续。
- 旋转、缩放、右键平移、跟随角色、镜头复位；手机支持单指旋转和双指缩放，玩具列表可横向滚动。
- 午后 / 傍晚光照切换、手动开启的合成环境音乐、敲琴音效、暂停 / 继续、PNG 场景截图、本次会话的成长小记。
- 所有模型、贴图、插图、缩略图和音频均在本地生成。没有外部图片、字体或音频请求。

## 交互

| 操作                   | 效果                               |
| ---------------------- | ---------------------------------- |
| 左键拖动 / 单指拖动    | 旋转镜头                           |
| 滚轮 / 双指缩放        | 放大缩小                           |

## 扩展结构

```text
src/
  world/
    primitives.ts       共享圆角几何、材质、造型辅助函数
    textures.ts         可复现木纹、布料及绘本 / 挂画纹理
    room.ts             房间、家具和静态装饰
  character/
    Xiaoer.ts           分层角色关节与姿态平滑混合
    actions.ts          玩耍动作注册表，输出关节姿态和空间偏移
  toys/
    types.ts            ToyDefinition、ToyModel 与 ActionKind 接口
    models.ts           独立玩具建模与玩具自身的动画
    registry.ts         玩具位置、接近点、朝向、持续时间、文案和工厂
  systems/
    navigation.ts       障碍物、A* 寻路与路径简化
    navigation.test.ts  全玩具可达性、42 组路线、出口与动作边界检查
    director.ts         walking / playing / idle 状态机及自动调度
    audio.ts            手势解锁的 Web Audio 环境声和琴音
  main.ts               场景装配、响应式镜头、输入和界面交互
  style.css             桌面与移动端界面
```

### 添加一个玩具

1. 在 `toys/models.ts`（或新文件）实现工厂，返回 `{ root, animate?, reset? }`。
2. 在 `toys/registry.ts` 添加配置。`position` 为世界坐标，`approach` 是小二落脚的位置，`facing` 为绕 Y 轴朝向弧度，`obstacle` 为地面碰撞圆。
3. 复用现有 `action`，或扩展 `ActionKind` 并在 `character/actions.ts` 注册动作函数。
4. 底部卡片、真实模型缩略图、鼠标选取和自动调度会自动接入。
5. 运行 `npm run test`，验证接近点和玩具间路线没有被家具堵住。

### 添加一个动作

动作函数接收动作时间（秒）与 `0..1` 进度，返回：

- `pose`：肩、肘、髋、膝、头部和身体的旋转 / 高度。
- `offset`（可选）：相对接近点的空间偏移，用于爬梯、滑行和骑乘。
- `facing`（可选）：动作过程中的朝向。

`Xiaoer.update()` 负责混合关节姿态。玩具自身的 `animate()` 与角色使用同一段动作时间。结束时应返回可行走的地面位置，避免把角色留在设施内部。

## 实现边界

本版采用程序化骨架层级和动作曲线，没有外部角色资产、动作捕捉或刚体物理引擎。小球、积木和绘本翻页为受控动画；成长小记只记录当前会话。后续可以沿已有接口替换成 glTF 蒙皮角色、AnimationMixer 动画片段或物理交互。
