# 小二的三维玩具房 · ds41-xiaoer-playroom

用 **Vite + Three.js** 从零程序化生成的一间温暖的 3D 玩具房：
Animal-Crossing（动森）式的圆润卡通造型，**奶油色 + 原木色**配色。
房间里住着 2 岁的亚洲小男孩 **小二**，他会自己跑去玩积木、推小车、抱皮球、爬城堡滑梯。

> 全部模型、贴图、动画都由代码生成，**没有任何外部图片 / 模型 / 音频资源**。

---

## 一、运行

```bash
cd deepseek/ds41-xiaoer-playroom
npm install
npm run dev
```

浏览器打开：**http://127.0.0.1:5273/**

生产构建 / 预览：

```bash
npm run build     # 产物在 dist/
npm run preview   # 预览构建结果
```

环境要求：Node.js ≥ 18（开发时使用 Node 22 + Vite 7 + three 0.185）。

## 二、操作说明

| 操作 | 效果 |
| --- | --- |
| **左键拖动** | 旋转视角（围绕房间中心，带阻尼） |
| **滚轮 / 双指** | 拉近 / 拉远（0.85m ~ 13m） |
| **右键拖动** | 平移视角 |
| **点击任意玩具** | 小二立刻走向该玩具并做出对应动作 |
| **左侧面板按钮** | 同“点击玩具”，🧱 积木 / 🚗 小汽车 / ⚽ 皮球 / 🏰 城堡滑梯 |
| **键盘 1 / 2 / 3 / 4** | 切换默认 / 正面 / 俯视 / 城堡 视角 |
| **键盘 5** | 小二脸部特写（相机自动站到他正前方） |
| **键盘 R** | 回到默认视角 |

鼠标悬停到玩具上时，玩具会微微发亮、指针变成手型，方便确认“可以点”。

### 小二会做的四件事

| 玩具 | 动作 |
| --- | --- |
| 🧱 积木 | 走到积木堆前**坐下**，一块一块把积木摞成塔（最多 9 块），搭好后站起来 |
| 🚗 小汽车 | 走到车后**蹲下**，双手扶着车尾推着车绕一小圈，再把车放回原位 |
| ⚽ 皮球 | 走到球边，**把球抱进怀里**，晃一晃，再轻轻放回地上 |
| 🏰 城堡滑梯 | 绕到城堡背面，**一级一级爬上梯子** → 走过平台 → 坐下 → **顺着滑道滑下来** → 站起来走开 |

不点他的时候，小二会**自主**在房间里挑一个玩具去玩（不会连续两次挑同一个）。

## 三、功能与技术要点

### 1. 程序化生成（零资源）

| 内容 | 实现 |
| --- | --- |
| 木地板 | Canvas 绘制木纹 + 板缝 + 随机短接缝，`CanvasTexture` |
| 墙面 | Canvas 绘制奶油色细竖纹 + 噪点 |
| **拼图爬爬垫** | Canvas 绘制 4×4 拼图块：底色 → 圆角方块 → 插口（挖洞）→ 凸起（补洞）→ 泡棉高光/压暗，凹凸咬合 |
| 皮球 | Canvas 绘制沙滩球式竖向色条 + 两极压暗 |
| 绘本封面 | Canvas 抽象童书图案（圆点 / 叶子 / 云朵 / 彩色球），每本不同 |
| 卡通光照 | `MeshToonMaterial` + 4 级 `DataTexture` 渐变图，得到柔和的色阶过渡 |
| 圆润造型 | `RoundedBoxGeometry` + `CapsuleGeometry` + `SphereGeometry` 组合出“软乎乎”的轮廓 |

### 2. 小二（`src/character/character.js`）

一个带骨骼层级的程序化角色，身高约 0.93m，**头身比约 1:3** 的幼儿比例：

- **五官**：黑眼珠 + 两处高光、眉毛、鼻头、上翘的微笑（半环 `TorusGeometry`）、腮红、耳朵；
- **头发**：锅盖头（半球壳）+ 后脑填充 + 刘海 + 两撮小翘毛 + 鬓角；
- **衣服**：奶白 T 恤（含领口、下摆）+ 牛仔背带裤（护胸、口袋、双肩带、木扣）+ 白袜子 + 白色小鞋（带薄荷色搭带）；
- **结构**：`root → body → hips → torso → { chest, neck → head, armL/R → elbow } / legL/R → knee → ankle`，方便做蹲、坐、抱、爬等动作；
- 脚下有一圈**柔和接触阴影**，加上实时投影让角色稳稳“踩”在地上。

### 3. 动画状态机（`src/character/animator.js`）

每个状态先算出一组**姿势目标值**（髋高、各关节角度…），再用与帧率无关的指数平滑贴到骨骼上，
所以状态之间永远是柔和过渡，不会瞬移。

状态：`idle / walk / sitBuild / squatPush / hugBall / climb / slide / getUp / cheer`，
外加自动眨眼（每 2.4~5.8 秒一次）。

### 4. 行为与寻路（`src/ai/brain.js` + `src/ai/nav.js`）

- **A\* 网格寻路**：把房间切成 9cm 网格，家具所占格子标记为不可走，
  找到路径后做“拉直”平滑，小二就会自然地绕开城堡、绘本架、绿植、收纳箱；
- **分轴滑动移动**：每帧把位移拆成 ≤4.5cm 的小步，分别尝试 (dx,dz)、(dx,0)、(0,dz)，
  任何一步都会先做碰撞检测——**结构上保证不会穿模**；
- **卡住重规划**：连续 0.8 秒几乎没有位移时，用 A\* 重新规划；
- **碰撞自检**：`window.__playroom.snapshot().violations` 会统计“走路时身处障碍物内”的帧数，
  正常应恒为 0（本次验证结果：0）；
- **点击引导**：走路途中点击新玩具会**立刻改道**；正在玩时点击会在当前动作告一段落（约 0.7s）后切换；
  爬梯 / 下滑过程中点击则**排队**，等这一趟滑完再响应。

### 5. 视角与拾取（`src/core/app.js`）

- `OrbitControls`：阻尼、极角限制（不会钻到地板下面）、右键平移、缩放范围限制；
- 相机目标点**轻微跟随**小二（系数 0.42、限幅 ±1.6m），既跟得住人又不会把房间晃出画；
  一旦用户拖动视角就停止跟随，把控制权完全交给用户；
- 拾取用 `Raycaster`，并区分“点击”和“拖动”：位移 > 8px 或按下超过 1.5s 视为拖动视角，不触发引导。

### 调试接口

页面暴露了 `window.__playroom`，方便二次验证：

```js
__playroom.snapshot()          // 当前状态、位置、相机、draw call、穿模计数
__playroom.advance(10)         // 以固定步长确定性推进 10 秒模拟（不依赖 rAF）
__playroom.guide('blocks')     // 让小二去玩积木
__playroom.setView('face')     // 切到脸部特写
__playroom.setCamera([x,y,z], [tx,ty,tz])
__playroom.freeze(true)        // 冻结模拟，方便截图 / 检查某个姿势
__playroom.pickAt(px, py)      // 某个屏幕像素打到了哪个玩具
__playroom.project(x, y, z)    // 世界坐标 → 屏幕像素
```

## 六、可以继续玩的方向

- 增加更多玩具（摇摇马、串珠、绘本），复用 `Brain.startInteraction` 的模式；
- 把 `animator.js` 的姿势目标值换成 `AnimationClip`，接入外部骨骼动画；
- 用 `InstancedMesh` 合并积木，进一步降低 draw call；
- 加音效与脚步声、给小二加语音气泡。
