# 鹈鹕骑自行车 · Pelican on a Bicycle

一个单文件、无外部依赖的循环动画：一只鹈鹕骑着自行车向前走。
`index.html` 里内联了整幅 SVG 和驱动动画的 JavaScript，不需要构建、不需要联网、不引用任何图片。

## 运行方式

任选一种：

```bash
# 1. 直接用浏览器打开（最简单）
open index.html            # macOS
# xdg-open index.html      # Linux
# start index.html         # Windows
```

```bash
# 2. 起一个本地静态服务器（推荐，行为最接近真实部署）
python3 -m http.server 8080
# 然后访问 http://localhost:8080/
```

```bash
# 3. Node 环境
npx serve .
```

## 交互

- **暂停 / 继续**：点击按钮，或按空格键。
- **速度滑块**：0×（静止）到 3×，右上角实时显示倍率。
- 调速后所有动作仍保持同一节拍——车轮、曲柄、踏板、双腿、背景滚动都由同一个相位量驱动。

## 实现要点

- **单一相位驱动**：`phase` 表示曲柄转过的圈数，所有可动部件都是它的纯函数，
  因此改速度只是改变 `dphase/dt`，不会破坏任何同步关系。
- **齿轮比固定 1.55**：车轮角度 = 曲柄角度 × 1.55，牙盘与曲柄同角，飞轮与车轮同角。
- **双腿用两骨 IK 求解**：脚踝固定在踏板上（偏移恒为 8px），由髋、踏板位置反解膝盖，
  膝盖始终朝前弯曲；大腿 86px、小腿 90px 长度严格守恒。
- **背景视差**：云 0.05×、远山 0.18×、灌木 0.5×、路面虚线 / 草丛 1.0×，
  地面位移 = `phase × 340px`，平铺瓦片取模循环，无缝。
- **无外部资源**：`url()` 只指向文件内定义的渐变和滤镜。
