# DS41 · 横格纸涂鸦 FPS

一个跑在浏览器里的第一人称射击游戏。整个战场是**一页横格笔记本**：米白纸张、蓝色圆珠笔轮廓、排线阴影，敌人是**红色火柴人**。地图里有集装箱、楼梯和高台。

用 Vite + Three.js 实现，**没有任何图片 / 模型 / 音频资源**——纸张、墨迹、火柴人、枪械、音效全部由代码在运行时生成。

```bash
cd deepseek/ds41-doodle-fps
npm install
npm run dev          # → http://127.0.0.1:5185
```

打开页面后点击「点击开始」，浏览器会锁定鼠标。

## 三把武器，手感刻意拉开

| | 圆珠笔步枪 | 马克笔霰弹枪 | 红笔武士刀 |
| --- | --- | --- | --- |
| 攻击方式 | 单发命中判定 | 9 颗弹丸扇形扩散 | 72° 扇形近战，可一次扫到多个 |
| 单发伤害 | 26 | 8.5 × 9 | 62 |
| 射速 / 冷却 | 0.105s（连发） | 0.82s | 0.44s |
| 弹匣 / 备弹 | 30 / 150 | 6 / 42 | 无弹药 |
| 换弹 | 1.55s | 2.6s | — |
| 特点 | 精准、后坐力小、弹道细 | 后坐力猛、屏幕抖、近距离一击必杀、泵动动画 | 移速 +18%、刀光笔触、命中「唰」声 |

- 换弹、切枪、开火各有独立动画：切枪从画面下方抬起，换弹时武器翻下，霰弹枪有泵动。
- 每击杀一个火柴人，步枪和霰弹枪各回补 4 发备弹；每 28 秒进一页（波次），备弹补满、敌人变多变硬。

## 敌人

红色火柴人（球头 + 圆点眼睛 + 生气嘴 + 四肢），会：

- **追击**玩家，撞墙时贴墙滑行并侧向绕路，被卡住会换方向；
- **爬楼梯**追到高台上（同一套 AABB 物理，可跨 0.56m 台阶）；
- 靠近后**起手 0.42s**（双臂举起）再挥击，命中扣 11 血并把你推开；
- 被打中有红色溅墨和受击闪白，被击杀会扑倒、缩小、在地面留下大团红墨。

子弹和近战都会被墙挡住（射线 vs AABB，取最近命中）；敌人攻击也做视线判定，躲在高台或掩体后面是安全的。

## 血量 / 弹药 / 击杀

- 左下角：生命条（手绘墨条），受伤 6 秒后缓慢回血；
- 右下角：当前武器名 + 弹匣 / 备弹；
- 顶部：击杀数与场上威胁数；右侧：武器栏；
- 受伤时红色晕染，击杀时蓝色墨迹晕染，命中出现红色十字标记；
- 死亡后显示击杀 / 存活时间 / 命中率，点击按钮或按 `Enter` 重开。

## 美术是怎么画出来的

全部是运行时 `canvas` 生成 + Three.js 几何体：

| 元素 | 做法 |
| --- | --- |
| 纸面 | 2048² canvas：米白底 + 轻微纤维颗粒 + 手抖的横格线 + 红色装订边线 + 打孔 |
| 蓝色描边 | 每个物体 = 纸色填充面 + `EdgesGeometry` 蓝线；再叠一层偏移 0.02 的淡线模拟「描两遍」 |
| 手绘抖动 | 顶点按「量化坐标哈希」做确定性抖动，同一条边的顶点不会裂开 |
| 线条呼吸（boil） | 每 0.1s 用新种子重新抖一遍所有描边，得到手绘动画的 stop-motion 感 |
| 排线阴影 | canvas 画斜向抖动排线，作为 `map` 贴在受光材质上；地面投影是羽化的排线贴图 |
| 墨迹 | 不规则贝塞尔墨团 + 甩出的墨滴，命中时按法线贴在墙/地面/敌人身上并淡出 |
| 飞溅 | 对象池 `Points`，带重力、落地反弹 |
| 枪口火光 / 刀光 | canvas 画放射星芒与弧形笔锋，贴在枪口 / 相机前的平面上 |
| 音效 | WebAudio 现场合成（噪声 + 滤波扫频 + 振荡器），步枪脆、霰弹闷、武士刀是扫频风声 |

地图实体用受光材质（`MeshLambertMaterial`）以获得立体明暗，线条和涂鸦本身是纯色，保证「墨线永远清晰」。


## 自动化验证

```bash
npm run dev            # 终端 A：保持 dev server 运行
npm run verify         # 终端 B：跑 77 项检查（自动开/关浏览器）
```

`verify.mjs` 用 Playwright 打开真实页面，通过页面里的 `window.__GAME__` 调试接口**固定步长**推进游戏，覆盖：

- 菜单 → 开始 → 暂停 → 死亡 → 重开 的完整流程；
- `W A S D` 四向位移、疾走更快、鼠标偏航/俯仰且俯仰限位；
- 撞墙不穿墙、不卡进几何体、能从高台下方穿过、**沿楼梯走上 3m 高台**、**跳上 1.3m 木箱**；
- 三把武器切换、开火耗弹、命中掉血、墙后敌人打不到、霰弹一击必杀、武士刀 62 伤害；
- `R` 换弹、空仓自动换弹、备弹扣减；
- 敌人追击、近身攻击扣血、**爬楼梯追到高台**；
- 血量归零进入结算、HUD 收起、显示击杀/存活/命中率、重开后状态与位置复位；
- 渲染批次 / 描边数量在合理范围、favicon 可加载；
- 全程无 JS 异常与 `console.error`。

最近一次运行：**77/77 通过**。截图见 `shots/`（可用 `node tools/capture.mjs` 重新生成）。

## 已知限制

- 无头浏览器里拿不到指针锁定，`window.__GAME__.start()` 会打开 `forceLook` 以便测试；真实浏览器不受影响。
- 物理是简化 AABB：角色是竖直方盒，不能侧身挤过窄缝，斜坡用台阶近似。
- 敌人寻路是「朝玩家走 + 贴墙滑 + 卡住换方向」，没有导航网格；复杂角落偶尔会绕一会儿，但最终能爬上高台。
