# ROAD RASH 41 — 暴力摩托 3D

90 年代《暴力摩托》(Road Rash) 风格的 3D 竞速格斗游戏。
Vite + TypeScript + Three.js，**所有模型、赛道、贴图、音效均由代码在运行时生成**，不依赖任何外部素材文件。

![style](https://img.shields.io/badge/engine-Three.js%20%2B%20Vite-ffb320) ![models](https://img.shields.io/badge/models-100%25%20procedural-37f0ff)

## 快速开始

```bash
cd deepseek/ds41-road-rash
npm install
npm run dev          # http://127.0.0.1:5183/
```

其他命令：

```bash
npm run build        # 类型检查 + 生产构建（输出 dist/）
npm run preview      # 预览生产构建 http://127.0.0.1:5184/
npm run typecheck    # 只做 tsc --noEmit
```

浏览器打开后按任意键/点击一次以解锁音频（浏览器自动播放策略要求）。

## 操作说明

| 按键 | 功能 |
| --- | --- |
| `W` / `↑` | 加速 |
| `S` / `↓` | 刹车 / 倒车 |
| `A` `D` / `←` `→` | 左右转向（高速时车身明显倾斜，最大约 47°） |
| `J` | **左拳** — 只能命中车身**左侧**近距离对手 |
| `K` | **右拳** — 只能命中车身**右侧**近距离对手 |
| `空格` | **挥棍** — 横扫，伤害最高，范围最远，但仍须贴身 |
| `R` | 重新开始比赛 |
| `P` / `Esc` | 暂停（预留） |

### 战斗规则

- 拳头射程约 **2.9 m**、横向有效范围 **1.55 m**；棍射程约 **3.7 m**、横向 **2.25 m**。
- **只有对应方向 + 近距离**才能命中：左拳打不到右侧的人，右拳打不到左侧的人；背后/远处挥空。
- 命中反馈：骑手出拳/挥棍动作、受击者踉跄抖动 + 横向击退、火花粒子、屏幕震动、合成音效、连击计数。
- 拳头 9 点伤害、棍 19 点伤害；血量归零 → 击倒（Knockdown）。

### 摔车与恢复

以下情况会**人车分离**并各自滑行翻滚：

- 血量耗尽（KO）
- 高速追尾/被追尾（相对速度 > 15.5 m/s）
- 与对向或同向汽车撞击（相对速度 > 7 m/s）
- 高速撞树、撞石头、撞路牌

滑行约 2.9 秒后自动扶车回到赛道（恢复 45 点血量、1.6 秒无敌），继续比赛。
摔车瞬间有轻微慢镜 + 镜头后拉 + 剧烈抖动。

## 玩法与系统

- **第三人称追尾视角**：镜头跟随车身姿态（约 6 m 后、2.4 m 高），速度越快 FOV 越大，转弯时随车身侧倾。
- **发车位置**：按《暴力摩托》传统，玩家从**最后一排**发车，需要一路超车打上去。
- **起伏弯道**：闭合赛道由「径向波浪圆 + 分层正弦高程」生成，全长约 **2260 m**，含长直线、S 弯、高速弯和上下坡；坡度会影响加减速（上坡掉速、下坡加速）。
- **路边景物**：松树/阔叶树/枯树（InstancedMesh）、岩石、灌木、路牌、弯道外侧红白护栏，全部按地形高度贴合。
- **5 名 AI 车手**：按赛车线走线，用物理公式 `v = √(a_lat / κ)` 提前减速入弯，会避让、超车、贴上来打人，也会互相斗殴。
- **对向汽车**：12 辆民用车双向行驶，对向车道来车是主要威胁，AI 会提前大幅避让。
- **真实排名**：按累计行驶距离 `totalS` 排序（不是简单的圈数），实时更新 `POS x/6`。
- **终点结算**：3 圈制，冲线后按名次/用时/命中数结算，`R` 或按钮重开。
- **复古仪表**：Canvas 手绘转速表（0–260 km/h、红区、指针缓动、数字读数、档位）、分段血条、POS/LAP/TIME 面板、CRT 扫描线 + 暗角 + 闪白。

## 项目结构

```
ds41-road-rash/
├── index.html          # 页面骨架 + HUD DOM
├── vite.config.ts
├── tsconfig.json
└── src/
    ├── main.ts         # 启动入口
    ├── config.ts       # 所有可调参数（物理/战斗/交通/镜头/渲染）
    ├── game.ts         # 场景、灯光、比赛流程、战斗结算、碰撞、镜头
    ├── track.ts        # 程序化赛道：中心线样条 + 等弧长重采样 + 路面/路肩/地形/标线网格
    ├── models.ts       # 代码生成模型：摩托、骑手、汽车、树、岩石、路牌、护栏
    ├── scenery.ts      # 路边景物布置（InstancedMesh）+ 碰撞体空间索引
    ├── entities.ts     # Racer 类：驾驶物理、倾斜、战斗计时、摔车布娃娃、动画
    ├── ai.ts           # AI 走线 / 入弯限速 / 避让超车 / 攻击决策
    ├── traffic.ts      # 民用车辆池与双向交通
    ├── particles.ts    # GPU 点精灵粒子池（火花/尘土/烟雾）
    ├── textures.ts     # Canvas 程序化贴图（沥青/泥土/草地/天空渐变）
    ├── audio.ts        # WebAudio 合成音效（引擎、拳、棍、撞击、摔车、倒计时）
    ├── hud.ts          # 仪表盘 Canvas 绘制 + DOM HUD + 结算表
    ├── input.ts        # 键盘状态与边沿触发
    ├── utils.ts        # 数学/随机/时间格式化
    └── style.css       # 复古街机 UI 样式
```

> `combat.ts` 没有单独文件，战斗判定集中在 `game.ts` 的 `resolveCombat()`。

## 技术要点

- **赛道坐标系统**：所有运动学量都在 `(totalS, x)` 赛道空间里计算 —— `totalS` 单调递增用于排名/圈数，`x` 为横向偏移。避免了闭合赛道环绕时的一切边界 bug，同时让「距离 / 左右方向」的战斗判定变成简单减法。
- **等弧长采样**：中心线用闭合 Catmull-Rom 样条，再按固定弧长（4 m）重采样，保证任意 `s` 处都能线性插值出位置/切线/右向量/上向量/曲率/坡度。
- **绘制调用优化**：刚体部件按颜色烘焙成顶点色合并成单一几何体 —— 一辆车 7 个 draw call、一辆摩托 4 个、一个骑手 9 个；全场约 180 次 draw call。
- **自适应画质**：滚动平均帧时间 > 30 ms 自动降分辨率/阴影，< 13.5 ms 再升回去。
- **无外部资源**：贴图用 Canvas 2D 生成，音效用 WebAudio 振荡器 + 噪声缓冲合成，模型全部由基础几何体拼装。

## 已验证

在 Chrome 中实际启动并逐项验证（数值取自运行时状态，非主观判断）：

- **驾驶**：按 `W` 速度从 0 升到 60+ m/s，`totalS` 持续增长；按 `A`/`D` 横向偏移变化、前叉转角 ±0.42 rad、车轮累计转角持续增加。
- **倾斜**：以 35 m/s 转向时 `lean` 达到 **±0.82 rad（≈47°）**；把车身局部上向量投影到赛道右向量上得到 **+0.70**，即确实向弯内（右）倾斜。
- **攻击方向**：把两名对手分别放在车身左 1.1 m / 右 1.1 m，按 `J` 只有左侧对手掉血（100→91），按 `K` 只有右侧对手掉血（100→91），验证「只能打对应方向」。
- **攻击动作**：出左拳时左肩关节 X 轴 −1.16→−1.64 rad、Y 轴 0→0.53 rad，肘部伸展；挥棍时右臂 X/Y/Z 三轴与躯干扭转同时变化。
- **AI 反击**：把 AI 放在玩家正后方 1.4 m，AI 自动 `startAttack('punchR')` 并使玩家掉血 100→91。
- **摔车分离**：58 m/s 摔车后骑手与摩托分离距离从 6.9 m 增长到 **17.3 m**，两者各自翻滚；约 2.9 s 后自动归位（分离距离回到 0）复活。撞对向车时 `crashKind` 为 `HEAD-ON`。
- **结算 / 重开**：把里程推到终点后阶段依次变为 `finished` → `results`，结算表 6 行（名次 + 用时 + 命中数），按 `R` 回到 `countdown` 且血量/里程/名次全部重置。
- **发车**：玩家位于最后一排，相机（6.4 m 后）与玩家之间没有其他车辆遮挡。
- **音效**：手势解锁后 `AudioContext` 启动，引擎/拳/棍/撞击/摔车/倒计时/结算全部合成函数调用无异常。
- **构建**：`tsc --noEmit` 无错误，`vite build` 成功（three 单独分包），生产构建在浏览器中同样正常运行。
